🚀 Local Physical NIC Packet Scanner Guide

To capture real live physical network packets (like Wireshark & Burp Suite):

  1. Install Npcap Driver: Run install_npcap.bat (bundled at installers/npcap-setup.exe).
  2. Run Streamlit SOC Dashboard: Right-click start_soc.bat and select Run as Administrator.
  3. Open Local SOC Cockpit: Go to http://localhost:8501 in your browser.
  4. Log In Credentials:
    • Admin: admin / Admin@123 (Full privileges)
    • Analyst: analyst / Analyst@123 (Read-only rules)
